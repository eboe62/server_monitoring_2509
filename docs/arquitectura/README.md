# AI Decisions

## Purpose

This directory contains significant AI-assisted decisions.

The objective is to:

* preserve decision history
* improve auditability
* improve governance traceability
* support incident reviews
* support ADR creation

---

## Scope

This directory does not store:

* conversations
* prompts
* routine interactions

This directory stores:

* architectural decisions
* hardening decisions
* governance decisions
* operational decisions

---

## Decision Authority

Decision records are historical artifacts.

Decision records do not create authority.

Authority remains governed by:

* User Instructions
* ADRs
* Governance Documents

---

## File Naming

YYYYMMDD-DECISION-XXXX.md

Example:

20260613-DECISION-0001.md
