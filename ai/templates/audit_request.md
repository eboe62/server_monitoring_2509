# Audit Request Template

## Audit Objective

Describe what must be audited.

Examples:

* security posture
* runtime configuration
* Docker hardening
* CI/CD controls
* observability

---

## Scope

List the systems included in the audit.

---

## Evidence Available

Provide:

* docker inspect outputs
* compose files
* logs
* metrics
* command outputs
* ADR references

---

## Audit Focus Areas

Evaluate:

* configuration
* runtime behaviour
* compliance
* operational risks
* security risks

---

## Required Output

For each finding provide:

* description
* evidence
* severity
* impact
* recommendation

---

## Severity Classification

Use:

* Informational
* Low
* Medium
* High
* Critical

---

## Deliverable Structure

1. Executive Summary
2. Findings
3. Risks
4. Recommendations
5. Validation Requirements

---

## Prohibited Behaviour

Do not:

* assume evidence
* generate implementation changes
* classify without justification
