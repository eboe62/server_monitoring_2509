# Repository Pull Request Template

## Objective

Generate pull request descriptions aligned with repository governance.

## Required Structure

### Objective

Describe the purpose of the change.

### Scope

List affected components.

### Files Modified

List modified files.

### Architectural Validation

Confirm compliance with:

* ADRs
* AI Constitution
* DevSecOps Principles

### Risks

Identify:

* runtime risks
* operational risks
* deployment risks

### Rollback

Describe rollback procedure.

## Constraints

* No marketing language.
* No unsupported claims.
* No assumptions.
* No hidden scope.
* No undocumented architectural changes.
* No future promises.

## Validation Questions

Before completing the PR description verify:

1. Are all modifications in scope?
2. Are ADRs respected?
3. Is rollback possible?
4. Are risks documented?
5. Are affected services identified?
