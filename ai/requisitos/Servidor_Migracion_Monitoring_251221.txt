==========================================
  2. CORRECCIONES NECESARIAS (ANTES / DESPUÉS)
==========================================

2.1 Imports Python (ejemplo)
----------------------------------
ANTES:
from common.config import log_info

DESPUÉS:
from monitoring.common.config import log_info

Corrección imprescindible tras migrar todo common/ a src/monitoring/common.

2.2 Rutas absolutas en scripts cron
----------------------------------

ANTES:
/usr/bin/python3 /opt/monitoring/log_ingestor/log_ingest_batch.py

DESPUÉS:
/usr/local/bin/python3 -m log_ingestor.log_ingest_batch

ANTES:
/5  * * * /app/cron/monitor.sh

DESPUÉS:
/5  * * * /app/ops/cron/monitor.sh

Ventajas:

Ejecuta el módulo, no el archivo → fiable tras reorganización
Compatible con contenedor Python
Reproduce entorno correcto sin depender de rutas absolutas

2.3 Dockerfile base
----------------------------------
ANTES:
COPY ./common /app/common

DESPUÉS:
COPY ./src /opt/monitoring/src
COPY ./requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

2.4 docker-compose (cron)
----------------------------------
ANTES:
build:
  context: ./cron

DESPUÉS:
build:
  context: ./ops/docker
  dockerfile: Dockerfile.cron

2.5 Correcciones críticas detectadas en correcciones_251203
----------------------------------
✔ 2.5.1 Conflictos Python internos
No se deben mezclar:
/usr/bin/python3 del host
/usr/local/bin/python3 del contenedor

librerías host vs contenedor
rutas internas vs rutas bind-mount

🔧 Acción IaC:
Todos los scripts deben ejecutarse exclusivamente:
python3 -m módulo
Siempre dentro del contenedor Python o mediante stack Docker.

✔ 2.5.2 Eliminación de rutas absolutas "host-dependientes"
Ejemplos detectados:
/opt/monitoring/common/config.py
/opt/monitoring/smtp_relay/...

🎯 Acción IaC:
Todo debe ser referenciado mediante paths relativos al contenedor:

/app/src/...
/app/ops/...

✔ 2.5.3 Problema detectado en imports: "ModuleNotFoundError: No module named 'common'"
Causa:
Estructura antigua no compatible con -m ni con PYTHONPATH.
Solución 100% IaC:
src/
  monitoring/
    common/

Y ejecutar SIEMPRE:
python3 -m log_ingestor.alert_risk

✔ 2.5.4 Modificación obligatoria de config.py
El archivo config.py debe:
evitar rutas absolutas
cargar .env desde ops/services/smtp_relay/.env
mantener compatibilidad contenedor/host
no realizar I/O fuera de la zona IaC
