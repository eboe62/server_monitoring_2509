6. LANGUAGE & FORMAT ISSUES
────────────────────────────────────────────────────────────────────────────────────────────────────

Finding: ADRs use mixed Spanish/English headers and vocabulary:
  • Status field uses Spanish: "Aprobado", "Rechazado", "Propuesto"
  • Expected: English: "APPROVED", "SUPERSEDED", "PROPOSED", "DEPRECATED"
  
  • Date field uses Spanish: "Fecha" instead of "Date"
  • Decision Type field: Missing completely (100% of ADRs)
  
  • Scope/Ámbito field: Some use "Ámbito" (Spanish), others use "Scope"
  • When present, often contains unvalidated values

Recommendation: Implement strict English-only header enforcement in template
and provide migration path for existing ADRs.
